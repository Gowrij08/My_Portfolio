### Phase 4: Deploy to GitHub Pages (20 minutes)

**Step 1: Create GitHub Repository**
```bash
# Go to github.com/new
# Create repo named "portfolio"
# Copy the repository URL
```

**Step 2: Initialize Git & Push**
```bash
cd portfolio
git init
git add .
git commit -m "Initial portfolio commit"
git remote add origin <YOUR_REPO_URL>
git branch -M main
git push -u origin main
```

**Step 3: Deploy**
```bash
# Install gh-pages if not already installed
npm install --save-dev gh-pages

# Build and deploy
npm run deploy
```

**Step 4: Enable GitHub Pages**
- Go to: GitHub → Settings → Pages
- Select: `gh-pages` branch
- Click Save
- Wait 5-10 minutes

✅ **Your portfolio is now live at**: `https://YOUR_USERNAME.github.io/portfolio/`

## 🆘 Troubleshooting

### Portfolio Not Loading Locally
```bash
rm -rf node_modules package-lock.json
npm install
npm start
```

### GitHub Pages Shows 404
- Check base-href in angular.json matches your repo name
- Wait 5-10 minutes for deployment
- Hard refresh in browser (Ctrl+Shift+R)

### Images Not Showing
- Ensure images in `src/assets/` folder
- Use relative paths in HTML
- Rebuild and redeploy

### Contact Form Not Working
- GitHub Pages can't process forms natively
- Use Formspree, EmailJS, or deploy to Vercel/Netlify
