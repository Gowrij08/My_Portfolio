## 🚀 Getting Started (3 Simple Steps)

### Step 1: Setup Locally (5 minutes)
```bash
cd portfolio
npm install
npm start
```
Open: `http://localhost:4200`

### Step 2: Customize Content (1-2 hours)
Update in these component files:
- Your name, title, description
- Your projects and achievements
- Your skills and experience
- Your contact information

### Step 3: Deploy (5-10 minutes)
```bash
npm run deploy
```

### Result 🎉
**Your portfolio goes live at**: `https://YOUR_USERNAME.github.io/portfolio/`

## 🎨 Customization Areas

### Easy Changes
Update these files to customize everything:

1. **Hero Section**
   - File: `src/app/components/hero/hero.component.ts`
   - Change: Title, subtitle, description, stats

2. **Projects**
   - File: `src/app/components/projects/projects.component.ts`
   - Change: Project names, descriptions, technologies, impact metrics

3. **Skills**
   - File: `src/app/components/skills/skills.component.ts`
   - Change: Skill categories and items

4. **Experience**
   - File: `src/app/components/resume/resume.component.ts`
   - Change: Job titles, companies, dates, achievements

5. **Contact**
   - File: `src/app/components/contact/contact.component.ts`
   - Change: Email, social links, Calendly URL

6. **Colors**
   - Search for: `#667eea` and `#764ba2` in component files
   - Replace with your brand colors
